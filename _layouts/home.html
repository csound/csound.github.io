Pling — Self-scheduling modal resonator percussion in 8 lines of code. 

instr Pling
  // Modal filter excited by an impulse with random pitch & damping
  aMode = mode(mpulse(ampdb(random:i(-22, 0)), p3),
               mtof:i(random:i(80, 100)), 10^(p3 - 1))
  aL, aR pan2 aMode, random:i(0, 1)
  out(aL, aR)
  // Recursively schedule the next event
  schedule("Pling", rnd:i(1), random:i(1, 4))
endin
schedule("Pling", 0, 3)

What's New in Csound 7

Expressive modern syntax meets 40 years of stability.

Csound 7.0 introduces explicit colon type annotations (sig:a, cutoff:k), user-defined struct types, function-style UDO definitions, and a modernized host API—while running classic Csound pieces from the 1980s without modification.

  • Explicit Types & Structs: Descriptive variable names and custom data structures.
  • Functional & Classic Styles: Write outall(moogladder:a(vco2:a(0.2, 440), 2000, 0.4)) or classic orchestra lines.
  • Zero-Install Browser Workflow: Learn interactively in the Csound Web IDE and FLOSS Manual.

Csound 7 Syntax Example subtractive-synth.csd 
instr SubSynth
  // Explicit variable typing in Csound 7
  amp:i    = p4
  freq:i   = p5
  env:k    = madsr:k(0.05, 0.3, 0.6, 0.4)
  osc1:a   = vco2:a(amp, freq)
  osc2:a   = vco2:a(amp, freq * 0.995)
  filtered:a = moogladder:a((osc1 + osc2) * 0.5, 4500 * env, 0.35)
  outall(filtered * env)
endin

schedule("SubSynth", 0, 2.5, 0.25, 220)

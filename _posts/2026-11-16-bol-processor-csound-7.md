The open-source [Bol Processor](https://bolprocessor.org/ "Visit!") project has been associated with Csound for decades. However, until now, this music composition and improvisation platform had only produced Csound scores, which it then asked the Csound console to convert to WAV files.

We are delighted to announce that **real-time Csound** is now fully supported by Bol Processor version 3.6.2. It runs beautifully on MacOS, Windows and Linux. I have conducted tests on Windows 10 and Linux Ubuntu. I am now awaiting the results of tests on Windows 11 and other Linux distributions.

Geeks can read [Real-time Csound: how it works](https://bolprocessor.org/tech-analysis-of-real-time-csound/)…

Enjoy the complementarity of these (arguably oldest) music creation platforms!

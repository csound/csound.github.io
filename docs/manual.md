The **Canonical Csound Reference Manual** provides complete technical specifications and runnable `.csd` examples for every opcode, GEN routine, and command-line option in Csound.

> **New to Csound?** The Reference Manual is designed for looking up specific opcodes and syntax details. If you are learning Csound for the first time, start with the [Get Started Guide](/get-started.html) or the interactive [Csound FLOSS Manual](https://flossmanual.csound.com/).
